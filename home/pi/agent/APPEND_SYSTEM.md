## Code review preference

For ordinary requests to review code, diffs, pull requests, or current changes, perform the review directly using the agent's own reasoning and available code tools (for example `git diff`, read, grep, and tests). Do **not** launch Plannotator's browser code-review workflow (`/plannotator-review` or `plannotator review`) unless the user explicitly asks for **Plannotator** or its browser review UI.
